A theme is just these lists. Change any of them and apply: the seed keeps the same story, told with your names and places. One item per line. Region and products on a place are optional: each carrier works one region, a region of * ships anywhere, and a place's own products win.

How the generator works
  • World first. Each seed builds its carriers before any invoice: names, the ways those names get shortened on paper, rates, open orders and the lanes each one runs. Every invoice agrees with that world.
  • Themes are lists. Names, carrier types, products, pick-up and delivery points (with optional regions and products) are plain lists, like the name bases in a fantasy map generator. Names come from their own random stream, so swapping a theme reskins the run without changing what happens.
  • Knobs. A scenario is a few probabilities over a base mix: how many scans or handwritten pages, unknown senders, duplicates, totals that don't add up.
  • Beats. A scenario also pins its key moment to the start, so "Duplicate storm" shows a duplicate in the first minute instead of whenever chance allows.
  • The day so far. Each seed also rolls a morning of earlier work, so the counters start where a real day would be.
  • Same seed, same demo. Copy the link and anyone gets exactly this run. Export JSON gives the full dataset. Read generator.js.
